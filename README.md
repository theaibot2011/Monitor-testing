# MonitorTest

A free, step-by-step monitor check you do with your own eyes: dead and stuck pixels, lines, light leaks, uniformity, colours, sharpness, viewing angles, burn-in, motion and more. It ends with a report you can print, save or share.

Everything runs in your browser. Nothing is uploaded, there's no tracking, and it works offline after the first visit.

## Try it

- **Live site:** https://monitortesting.netlify.app
- **GitHub Pages:** https://theaibot2011.github.io/Monitor-testing/v3/

## What's in this repo

- `source/` - the source code, built with React, TypeScript, Vite and Tailwind
- `v3/` - the built version that runs on GitHub Pages

## Run it yourself

    cd source
    npm install
    npm run dev

Then open the address it prints (usually http://localhost:5173). More details are in [source/README.md](source/README.md).
